Tempo

Getting Started

Welcome back. In the previous session we built the mental model. Today we move from concepts into practice. By the end of this session you should be able to connect to Tempo, obtain test funds, and send your first real payments — including transfers with memos.

Goals for This Session

  • Understand how to connect to Tempo
  • Fund an account using the faucet
  • Send a basic TIP-20 transfer
  • Attach a memo to a payment
  • Use the explorer effectively
  • Recognize the difference between a normal EVM transaction and a Tempo-native experience
These are the practical foundations. Everything later in the series (TIP-20 details, Tempo Transactions, policies, agentic payments) assumes you can do these steps comfortably.

Network Basics

  • Mainnet Chain ID: 4217
  • Currency: USD stablecoins (no native gas token)
  • Block time: ~0.5 seconds
  • Finality: Deterministic, sub-second
Key facts to remember. There is no volatile native token. Fees are paid in USD-denominated TIP-20 stablecoins. Finality is fast and deterministic.

Connecting to Tempo

flowchart LR Wallet[Wallet] --> RPC[RPC Endpoint] RPC --> Node[Tempo Node] Node --> Chain[Tempo Network]

Standard EVM wallet connection flow

Connecting is straightforward because Tempo is EVM compatible. You add the network to your wallet using the RPC endpoint and Chain ID. Most common wallets work.

What You Need to Connect

  • RPC URL
  • Chain ID (4217 for mainnet)
  • A wallet that supports custom EVM networks
  • Optionally: Tempo Wallet for the best native experience
You can use MetaMask, Rabby, or other EVM wallets. There is also a Tempo-native wallet experience that understands Tempo Transactions and fee tokens more cleanly. For learning, either approach works.

Getting Funds

flowchart LR Faucet[Faucet] --> Wallet[Your Wallet] Wallet --> TIP20[TIP-20 Stablecoins]

Faucet provides testnet TIP-20 tokens

On testnet you use the official faucet to receive TIP-20 tokens. These tokens are what you will use both for transfers and for paying fees. Remember: there is no separate gas token to claim.

Sending Your First Payment

flowchart TB A[Select TIP-20 token] --> B[Enter recipient] B --> C[Enter amount] C --> D[Optional: attach memo] D --> E[Submit transaction] E --> F[Finalized in ~0.5s]

Basic payment flow

The basic flow looks familiar if you have used any EVM chain. The important differences appear in the details: fee token selection, memos, and the speed of finality.

Transfer Memos

TIP-20 transfers can carry a short memo.

  • Useful for invoices and reconciliation
  • Similar in spirit to traditional payment references
  • Stored onchain with the transfer
Memos are one of the first places where Tempo feels purpose-built for payments. In traditional systems every transfer usually carries a reference. TIP-20 brings that idea onchain in a simple way. We will go much deeper into TIP-20 later, but you should start using memos from the first payment.

What Happens Under the Hood

flowchart TB User[User signs tx] --> Fee[Fee paid in TIP-20] Fee --> Lane[Payment lane] Lane --> Consensus[Simplex BFT] Consensus --> Final[Finalized state]

Simplified path of a payment transaction

Even a simple transfer benefits from the design we discussed earlier. The fee is paid in a stablecoin. The transaction can use the payment lane. Finality arrives quickly and deterministically.

Using the Explorer

  • Search by transaction hash
  • Search by address
  • Inspect token transfers
  • Observe finality and timing
After sending a transaction, always look it up in the explorer. Pay attention to how quickly it finalizes and what information is visible (including any memo). Getting comfortable with the explorer early saves time later.

Regular EVM vs Tempo Experience

flowchart LR subgraph Regular R1[Need native gas token] R2[Probabilistic finality] R3[No native memo] end subgraph Tempo T1[Pay fees in stablecoins] T2[Deterministic finality] T3[Native memo support] end

Key experiential differences even for simple transfers

Even before we use advanced features such as Tempo Transactions or fee sponsorship, the basic experience already feels different. You do not manage a separate gas token. Finality is fast and certain. Memos are available natively.

Practical Checklist

  1. Add Tempo network to your wallet
  2. Request tokens from the faucet
  3. Send a simple TIP-20 transfer
  4. Send a second transfer with a memo
  5. Inspect both transactions in the explorer
This is the minimum set of actions you should complete. Do not move on until you have successfully done all five steps. These actions form the foundation for every later hands-on session.

Common Pitfalls

  • Forgetting that fees are paid in TIP-20 (not a native token)
  • Using the wrong chain ID
  • Not waiting for finality before assuming the payment is settled
  • Ignoring the memo field
These are the most common early mistakes. The fee token mental model is the one that takes the longest for people coming from Ethereum or typical L2s.

Core Tools You Will Use

  • Faucet — obtain test funds
  • Explorer — inspect transactions and accounts
  • Tempo Wallet — native experience (optional but recommended)
  • RPC endpoints — connect wallets and tools
You do not need every advanced tool yet. These four are enough to get productive. Later we will add Foundry, SDKs, the indexer, and the CLI.
