## Tempo Demo Track

The Tempo slide series is paired with a hands-on demo curriculum in [notes/004_tempo/demos](notes/004_tempo/demos). It is designed for one-hour classes where each session has one polished live demo, one student README, and a production-minded failure-case walkthrough.

To view all slides locally

`git clone https://github.com/metana-bootcamp/tech-talks.git`

Then go into the directory and init the submodules:

```bash
$ cd ./tech-talks
$ git submodule update --init 
```
